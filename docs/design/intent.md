# Intent

- **Intent sources:** intent is extracted, not entered by hand, from:
  - the PR description;
  - Jira tickets mentioned in the description, commits or branch name;
  - the code itself, inferred from what the change actually does.

  Stated intent (description, tickets) and intent inferred from the code are compared. A mismatch between them is a finding in itself: the change does something nobody asked for, or misses something that was asked. So the two are shown side by side only when they disagree. When they agree, one line says the change does what was asked, and the full list of behavior changes sits behind a toggle. Always showing both was the first version. It said the same intent twice and made the intent panel the biggest thing on the page.
- **Intent is one line.** Before the code the reviewer reads what the change does, as behavior a user or caller notices, in at most 20 words: Claude's once it has run, and the description's first sentence before. A brief of three lines was the version before: what the change does; how it runs through the system, from where it's reached to what it ends in, by the names of its page, routes and modules; and what to watch, at most two things the first line leaves out, something nobody asked for first, then what changes for code, users or data that already exist. Before a run the code wrote the other two lines itself, the overview's directories in call order with their entry points and the changed definitions code outside the PR uses, with how many uses. On graal #15134 the three lines wrapped between the title and the code, and the reviewer had come for the code: the directories are the architecture, the same on every PR and already the overview's, the uses are on the code, under each part's “Used unchanged in”, and what nobody asked for is a mismatch, marked on the code it rests on. The intent pass writes only the summary now, so a run pays for nothing the page doesn't show. One sentence was the version before the brief, and said the title again in more words, which the task still forbids. A watch line that could name what looks wrong was tried on the evals and dropped: it said a finding before its card did, a second time.
